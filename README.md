# 🎮 Tic Tac Toe Web Application

A simple and interactive **Tic Tac Toe** game built using **HTML**, **CSS**, and **JavaScript**.  
Play against a friend on the same device with a responsive and visually appealing interface.

---

## 📁 Files Included

- **index.html** – Main structure of the game  
- **style.css** – Styling for the board, cells, buttons, and animations  
- **script.js** – JavaScript logic for gameplay, win detection, and reset functionality  

---

## ⚙️ Features

- Classic **3x3 Tic Tac Toe** game  
- Displays **current player's turn**  
- Detects **win** or **tie** automatically  
- Highlights winning combination with **glow animation**  
- Responsive design for **desktop and mobile**  
- Keyboard accessibility: use **Enter** or **Space** to play  
- Reset button to start a **new game**  

---

## 🛠️ Technologies Used

- **HTML5** – Semantic markup for the game structure  
- **CSS3** – Styling, animations, and responsive design  
- **JavaScript (ES6)** – Game logic, event handling, and win detection
